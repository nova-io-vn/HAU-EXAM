# Kiểm thử Mobile

`npm run typecheck` kiểm tra TypeScript và hiện đã PASS. `npm run lint` dùng Expo lint khi môi trường dependency đầy đủ. `npm run build` là Expo export web, không phải Android APK.

Các flow screen đã có: auth, question, review, AI job, notification, profile, exam và admin. Native Android/iOS build, camera/file picker trên thiết bị thật, WebSocket reconnect thật và OS push provider là NOT TESTED trong môi trường hiện tại.
