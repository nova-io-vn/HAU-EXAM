# Mobile Design System

- Background: `#F5F5F7`
- Surface: `#FFFFFF`
- Primary text: `#1D1D1F`
- Secondary text: `#6E6E73`
- Accent: `#0071E3`
- Primary dark action: `#111111`

Buttons/inputs: 8-12px radius.
Cards: 12-16px.
Sheets/modals: 16-20px.
Badge: pill.

Ưu tiên:
- safe area
- keyboard-safe form
- touch target đủ lớn
- FlatList cho danh sách lớn
- bottom sheet cho filter/action phụ
- skeleton/loading/error/empty states

Không copy desktop table nguyên xi xuống mobile.
