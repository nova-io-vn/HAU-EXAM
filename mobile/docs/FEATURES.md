# Mobile Feature Scope

## Auth
Login, register, pending approval, forgot/reset password.

## Profile
View/update own profile.

## Questions
My Questions, detail, create/edit, submit, image attachment.

## Review
SUBJECT_ADMIN review queue, approve/reject/request revision theo faculty.

## AI
Document upload, generation job, job state, preview result, chatbot.

## Notifications
List, unread count, mark read, realtime.

## Exam
Ưu tiên list/detail/generated exam preview. Matrix editor phức tạp có thể Web-first.

## Admin
Pending registrations, quick approve/reject, user lookup/detail.
