# 3. Công nghệ sử dụng

| Nhóm | Công nghệ thực tế |
|---|---|
| Backend | Java 21, Maven, Spring Boot 4.1.1 |
| Cloud | Spring Cloud 2025.1.3, Eureka, Spring Cloud Gateway |
| Dữ liệu | PostgreSQL, Spring Data JPA, Flyway |
| Messaging | RabbitMQ, Spring AMQP |
| Cache/tạm | Redis, Spring Data Redis |
| Mapping/JSON | Jackson, MapStruct |
| Bảo mật | Spring Security, BCrypt, OAuth2 Resource Server, Nimbus JWT |
| Web | React, Vite, React Router |
| Mobile | React Native trên Expo, TypeScript, Expo Router |
| Kiểm thử | JUnit/Spring Test, Mockito, Playwright |
| Đóng gói | Dockerfile multi-stage và Docker Compose |

Version chi tiết được khóa trong root `pom.xml`, các `pom.xml` module và `package.json` tương ứng.
