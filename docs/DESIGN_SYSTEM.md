# Design System Reference

Frontend phải tuân thủ file design system chính của dự án:
`HAU_EXAM_BANK_DESIGN_SYSTEM.md`.

Tinh thần: - Apple-inspired nhưng không clone Apple. - Tối giản, rõ
ràng, chuyên nghiệp. - Nền `#F5F5F7`, surface trắng, text `#1D1D1F`,
accent `#0071E3`. - Không gradient trang trí. - Không shadow nặng. -
Không glassmorphism đại trà. - Không bo góc quá mức. - Ưu tiên
typography, spacing, hierarchy và accessibility.

Nếu design system chi tiết được đặt tại
`frontend/docs/DESIGN_SYSTEM.md`, file đó là nguồn tham chiếu trực tiếp
cho frontend.
