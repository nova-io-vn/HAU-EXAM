# 9. AI

AI Service sở hữu document, AI job, provider adapter, structured result và chatbot API. Không có AI Worker microservice riêng; consumer xử lý nền nằm trong AI Service.

```text
Client -> Gateway -> POST AI request -> 202 + jobId
                                  -> RabbitMQ
                                  -> AI consumer/provider
                                  -> ai.generation.completed
                                  -> Question fetch result qua internal REST
                                  -> Question source=AI, status=DRAFT
```

Kết quả được parse/validate trước khi nhập vào Question. Event completion dùng context `requestedBy`, `facultyId`, `subjectId`, `chapterId`, `topicId`, `resultReference`. Question không truy cập `ai_db`.

Provider thật phụ thuộc `AI_API_KEY` và môi trường; E2E Web hiện dùng fixture deterministic, chưa phải live provider test.
